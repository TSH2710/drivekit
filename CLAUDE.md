## Project Overview

DriveKit Live is a Shopify-integrated e-commerce storefront for DriveKit products, built on the Shogo platform. It's a Vite + React + Tailwind + shadcn/ui frontend with a Hono backend server, using Prisma for database access and MobX for state management.

## Commands

```bash
# Dev (client only)
bun run dev

# Dev (full stack — server + client)
bun run dev:full

# Build
bun run build

# Start production server
bun run start

# Database
bun run db:generate        # Generate Prisma client after schema changes
bun run db:migrate:dev     # Create dev migration
bun run db:migrate:deploy  # Deploy migrations to production
bun run db:push            # Push schema changes without migration (prototyping)
bun run db:studio          # Open Prisma Studio

# Type checking
npx tsc --noEmit
```

## Architecture

**Entry points:**
- `server.tsx` — Hono server (port 3001), serves API + static files. **Auto-generated by Shogo SDK — do not edit.**
- `src/App.tsx` — React entry, renders `DriveKitStore` component.
- `vite.config.ts` — Dev server on port 3000, proxies `/api` to server on 3001.

**Routing layers:**
1. **Auto-generated CRUD routes** (`src/generated/`) — Prisma models get auto-generated REST endpoints at `/api/<model>s`. Triggered by `bun run generate`.
2. **Custom routes** (`custom-routes.ts`) — Edit this file for non-CRUD backend logic (Shopify sync, auth, email, etc.). Mounted at `/api`. This is the main backend editing surface.

**Key backend files** (all in `src/lib/`):
- `shopify-helpers.ts` — Shopify OAuth, API calls, product fetching
- `email-helpers.ts` — Email sending via Resend or SMTP
- `auth-helpers.ts` — Password hashing, session management, signup flow
- `admin-middleware.ts` — Admin auth middleware for protected routes
- `product-cache.ts` — Product caching, image generation, Shopify product shaping
- `db.ts` — Prisma client singleton (PostgreSQL in production, SQLite/libSQL locally)

**Frontend** lives in `src/components/`:
- `DriveKitStore.tsx` — Main store component (product grid, cart, checkout)
- `AdminDashboard.tsx` — Admin panel (orders, products, emails, site content)
- `SiteEditor.tsx` — CMS-style content editor
- `OrderManagement.tsx` — Order list and detail views
- `ProductEditor.tsx` — Product override editing
- `ImageGenerator.tsx` — AI image generation for products
- UI components in `src/components/ui/` (shadcn/ui)

**State:** MobX stores in `src/stores/` manage cart, auth, and UI state.

**Database:** Prisma 7 with PostgreSQL (prod) or SQLite/libSQL (local). Schema in `prisma/schema.prisma`. Models: User, Order, OrderItem, ProductOverride, Review, SiteContent, WaitlistEntry, NewsletterSubscriber, EmailLog.

## Key Patterns

- The `@` path alias maps to `./src/` (configured in tsconfig and vite).
- `products.json` at the project root is a local product cache used by the store.
- Shopify product images live in `dash_imgs/`, `dash_mat_imgs/`, `drive_covers/`.
- The server auto-detects database provider from `DATABASE_URL` (PostgreSQL vs SQLite).
- Session-based auth using in-memory maps (not JWT), with optional admin middleware.
